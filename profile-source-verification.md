## 3. Projects Showcase & Verification Details

### Project 1: CHAINPROOF
* **Category**: Research Direction (Major Project — Started August 2026)
* **Status**: *Just started — August 2026. No code or results yet.*
* **Subtitle**: Evidence-Based Verification of Software Supply-Chain Integrity
* **Overview**: Investigates which combinations of code signatures, build provenance (SLSA framework), Software Bills of Materials (SBOMs), and reproducible builds actually catch tampering in an open-source software supply chain versus which ones just look secure.
* **Problem Statement**: Software supply-chain attacks (tampered dependencies, compromised build pipelines, poisoned containers) are common breach vectors, yet verification methods are often adopted without empirical testing against actual tampering scenarios.
* **Planned Approach**: Construct a source-to-artifact evidence chain (commit, build, artifact). Generate SBOMs (using Syft), verify build provenance against SLSA, and test build reproducibility against a labelled set of tampering scenarios.
* **Expected Output**: An open-source verifier, a labelled tampering benchmark, and reproducible experiment results.
* **Research Stack**: Code Signatures, Syft (SBOM), SLSA Framework, Reproducible Builds, Supply Chain Security, Tampering Benchmark.
* **Repository & Demo Links**: None present on portfolio (*Portfolio text explicitly states: "No code or results yet. This section will be updated with a repo link, real findings, and data as the project develops."*).
